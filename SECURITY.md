# Security

## Reporting a vulnerability

Please report it privately, not in a public issue:
**[Report a vulnerability](https://github.com/Wallisgareth004/memory-warden/security/advisories/new)**
(the repo's Security tab → "Report a vulnerability").

Include what you found, how to reproduce it and what it affects. I aim to reply
within a week. Please give a fix time to land before you talk about it publicly.

## Supported versions

Only the latest commit on `main` is supported.
